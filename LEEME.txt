APPMAZ AUDIO TÁCTIL V2 — ENVÍO DIRECTO Y SELECTOR DE MODELO

INSTALACIÓN
Sube todos los archivos de esta carpeta a una carpeta HTTPS distinta de la versión
anterior, por ejemplo https://appmaz.vip/audio-tactil/. Abre index.html.
No basta con abrir el HTML descargado ni con subir únicamente index.html.
En iPhone: Safari > Compartir > Añadir a pantalla de inicio.
En Android: Chrome > Instalar aplicación / Añadir a pantalla de inicio.

USO
1. Introduce tu código exacto de tres letras y la API key de OpenAI.
2. Configura la frase de detención, elige el modelo de lenguaje y crea listas con nombre y prompt.
3. Pulsa Usar lista. Aparece la pantalla negra y se pide permiso de micrófono
   si hace falta. El micrófono queda desactivado: no se inicia la escucha.
4. Mantén un dedo quieto en la pantalla negra durante UN SEGUNDO. Un toque
   corto, un desplazamiento o una pulsación en Volver no inicia la escucha.
5. Espera a que aparezca Escuchando antes de hablar. Puede haber unos segundos
   de conexión con OpenAI después de mantener pulsado.
6. Di la frase de detención para terminar. El audio se detiene, el modelo analiza
   la transcripción con el prompt seleccionado y la respuesta final aparece
   en la pantalla negra. No se muestra allí la transcripción.
7. La respuesta también se envía por GET a Appmaz. Permanece visible hasta
   iniciar otra escucha o salir. Para otra escucha, mantén de nuevo un segundo.
8. Mantén Volver DOS SEGUNDOS para salir. Se apaga por completo el micrófono.

QUÉ SE ENVÍA Y CUÁNDO
- Al entrar en la pantalla negra: NO se consulta ni se escribe en la API de
  Appmaz, ni se abre una conexión con OpenAI. Se gestiona el permiso local.
- No se consulta WIKISTOP: esta versión solo se activa con la pulsación.
- Tras la pulsación de un segundo: se conecta con OpenAI; el audio se activa
  cuando el canal está listo. La etiqueta Escuchando refleja ese momento.
- Tras la frase de detención: se manda la transcripción y el prompt a OpenAI.
- Al recibir la respuesta final: se muestra en pantalla y se envía a
  https://appmaz.vip/api/storedata.php?user=CODIGO&data=RESPUESTA
  Los parámetros se codifican para conservar tildes, espacios y símbolos.
- Al tener la respuesta, se envía directamente a storedata.php sin leer antes.
  Después se consulta getdata.php. Si no coincide, se reenvía cada segundo
  durante un máximo de diez segundos (hasta diez intentos, incluido el inicial).
  Se detienen los reintentos en cuanto se confirma el resultado. Los reintentos
  solo repiten el GET de Appmaz: NO vuelven a llamar al modelo de lenguaje.
  No hay consultas mientras espera una pulsación ni hace falta WIKISTOP.

Si falla el envío, el resultado sigue visible. También se guarda como pendiente
localmente. Mantén Volver dos segundos para revisar el error y reintentar.
No uses simultáneamente esta versión y la versión WIKISTOP con el mismo código:
ambas escriben en el mismo campo remoto. La respuesta WIKISTOP ya no tiene un
significado especial en esta versión táctil.

CONFIGURACIÓN
Las listas y la configuración de la versión anterior se importan una vez si
están guardadas en el mismo origen. Después se guardan de forma independiente.
Las respuestas pendientes de la versión anterior no se importan ni se alteran.
Cambiar de dominio/navegador no transfiere automáticamente los datos.

REQUISITOS Y LÍMITES
Usa HTTPS, Internet y la app abierta con el teléfono desbloqueado.
El navegador decide si recuerda el permiso de micrófono. La pista se mantiene
DESACTIVADA entre escuchas para reutilizar el permiso. El sistema puede seguir
mostrando su indicador de micrófono. Al salir se detienen las pistas.
Se solicita mantener la pantalla encendida si el navegador lo permite.
Si la app deja de estar en primer plano durante la escucha, el audio se detiene.

Para evitar CORS, aloja esta carpeta en https://appmaz.vip. Si la alojas en
GitHub Pages u otro dominio, las APIs de Appmaz deben permitir ese origen.
getdata.php acepta texto plano, una cadena JSON o un objeto con data/text/content.
Los límites de longitud de URL del servidor se aplican al envío GET.
La API key no está incluida en los archivos; se introduce y guarda en el navegador.
La conexión de audio se conserva. El selector permite GPT-5 Nano con razonamiento
mínimo o GPT-4.1 mini sin parámetros de razonamiento. La elección se guarda.
En Última sesión se registran el tiempo del modelo y el del envío por separado.
La velocidad real depende del prompt, la carga del servicio y la conexión.

COMPROBACIONES
Pruebas simuladas superadas: ninguna petición al entrar, pista desactivada,
pulsación de un segundo, toques cortos, cancelación/movimiento/multitáctil,
Volver independiente de dos segundos, dos ciclos consecutivos, solo respuesta
final en el GET, resultado visible incluso si falla el envío, cancelación al
salir y gestión de permiso denegado. Sintaxis JavaScript verificada.
No se ha verificado esta versión con un micrófono real, las APIs reales ni
con teléfonos físicos. El archivo original y la versión WIKISTOP se conservan.

ACTUALIZAR DESDE LA VERSIÓN TÁCTIL ANTERIOR
Sustituye TODOS los archivos de la carpeta por los de este ZIP. Cierra y vuelve
a abrir la app para activar la nueva caché. Las listas y ajustes se conservan.
Si no ves el selector Modelo de lenguaje, recarga la web y vuelve a abrirla.

Comprobaciones adicionales de V2: envío inicial antes de leer, reintentos cada
segundo, parada al confirmar, plazo máximo de diez segundos, peticiones lentas,
cancelación al salir y parámetros correctos para ambos modelos.
